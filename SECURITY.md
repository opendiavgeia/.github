# Security

To report a vulnerability in opendiavgeia.com, its MCP server at `https://opendiavgeia.com/mcp` or its sign-in, use **Report a vulnerability** on the repository's Security tab, or write to contact@opendiavgeia.com. Please don't open a public issue.

Say what you found, how to reproduce it and what it lets someone do. Test only against your own account, and don't read, change or delete anyone else's data.
