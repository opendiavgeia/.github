# opendiavgeia

[opendiavgeia.com](https://opendiavgeia.com) is an independent search over [Diavgeia](https://diavgeia.gov.gr), where Greek public bodies post their decisions. It adds up what each ministry, municipality, region and hospital paid, and to whom, by year and by tax number (ΑΦΜ), and links every figure to the decision it came from.

Το opendiavgeia.com είναι μια ανεξάρτητη αναζήτηση στη Διαύγεια: τι πλήρωσε κάθε φορέας, σε ποιον και πότε, με σύνδεσμο στην απόφαση από την οποία προκύπτει κάθε ποσό.

- **Site:** [opendiavgeia.com](https://opendiavgeia.com)
- **Ask AI:** [opendiavgeia.com/ask](https://opendiavgeia.com/ask), questions in Greek or English
- **MCP server:** `https://opendiavgeia.com/mcp`, for Claude, ChatGPT, Cursor and VS Code ([setup](https://github.com/opendiavgeia/mcp))
- **For AI assistants:** [opendiavgeia.com/llms.txt](https://opendiavgeia.com/llms.txt)
- **Contact:** contact@opendiavgeia.com

### Data

Decisions come from Diavgeia's open API and, back to 2010, from the [glossAPI/diavgeia](https://huggingface.co/datasets/glossAPI/diavgeia) archive (CC BY 4.0). [How amounts are counted](https://opendiavgeia.com/about).

opendiavgeia is not affiliated with diavgeia.gov.gr or any public authority.
