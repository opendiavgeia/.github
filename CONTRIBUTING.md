# Contributing

The site's own code isn't public. What helps most:

- **Issues** for wrong or missing figures, names the tools can't find, and clients that won't connect. Include the page address or the question you asked, and what you expected.
- **Pull requests** to the docs and the client setup in [opendiavgeia/mcp](https://github.com/opendiavgeia/mcp): a client that's missing, steps that changed, a typo.

Keep private people out of issues and examples: describe them as "a person" rather than by name.
